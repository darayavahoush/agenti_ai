# Pinned 2026-08-22 -- every package below is version-locked so a fresh
# `pip install` always resolves the same set of wheels, instead of pulling
# whatever's newest that day (which is how the epitran/editdistance build
# broke on a fresh Python 3.14 venv this session -- a floating dependency
# picked a version with no prebuilt wheel and fell back to compiling from
# source). Bump versions deliberately, one at a time, testing after each.
#
# transformers is capped in the 4.x line (was already `<5` before this
# pin) -- transformers 5.x is out on PyPI but nothing in this codebase has
# been verified against its breaking changes, so don't jump there blindly.
# Same reasoning for pandas (kept on 2.x, not the new 3.x line) and
# opencv-python (kept on 4.x, not the new 5.x line): pinning to the latest
# *within the already-proven major version* rather than the newest major
# release, since those majors haven't been tested against this codebase's
# audio/CV pipeline.
